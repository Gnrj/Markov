# Project Description
- Компилятор Маркова - это реализация компилятора для работы с марковскими алгоритмами, написанная на языке программирования Си. Проект предоставляет возможность компиляции и выполнения марковских подстановок.
# Markov's Description
- Алгоритм Маркова работает по правилам, которые описаны в следующей статье: https://en.wikipedia.org/wiki/Markov_algorithm 
# Makefile
- Makefile поддерживает следующие таргеты:
```
make help
```
- Выводит информацию про все таргеты

```
make compile
```
- Компилирует файл, и получается исполняемый файл *Markov*

```
make run
```
- Компилирует файл и запускает программу

```
make clean
```
- Удаляет исполняемый файл
